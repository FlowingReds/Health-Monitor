# Linux System Health Monitor - Work Log

## Planning 

Time spent: 20 minutes

This was the easiest part of the project. I researched online and looked for something that I thought would be cool and wanted to make
because I wanted to make a script that could actually provide my system with something of value. I went with the Health monitor because it seemed like something useful to see how much of my system is being used.

## Creating the script

Time spent: 1 hour

I wanted to make a simple menu that was minimal that let the user check the CPU,RAM, disk usage, and the up time. I also added a way to save the system checks to a log file so they can be viewed later.


## Changes Made

Time spent: 30 minutes

I originally had a few other things planned. One would warn when system usage was to high, another would show the top 5 processes using memory, and another would run automatic checks. I decided to remove them because I didn't think they were really necessary for what I wanted the script to do.


## Testing and Fixing Errors

Time Spent: 10 minutes

When i first tried running the script, I got an error because I made some mistakes. I was able to figure them out. One was that I used the wrong bracket, which was an easy fix, and the other one was that I forgot a quotation mark in one of my echo statements. After that I got the script working.


## What I Learned

I learned more about how to use Bash commands. I haven't really used Bash that much before, but I learned that it can be useful for creating simple scripts to check system information, or do others tasks on Linux.
